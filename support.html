Quick start 1. Add your server’s address, SSH port and username. 2. Save a password or import an unencrypted Ed25519 OpenSSH / ECDSA PEM private key. 3. Save to start a connection test. Verify the SHA256 host fingerprint through a trusted channel and approve to continue authentication. 4. On success, choose Create your first button. Select a read-only example or enter a trusted non-interactive command, save, then tap its button. Connection issues Check SSH is enabled, the port is reachable and the username is correct. RSA, encrypted keys, keyboard-interactive/MFA and interactive sudo prompts are not supported. A sleeping Mac must already be reachable for SSH; Wake-on-LAN is not included. Safety Confirmations are on by default. Only one command runs at a time. Connecting has a 15-second overall limit; commands have a configurable 15–300-second limit. Output is capped at 64 KB. Cancellation closes the connection, but does not guarantee the server stopped its process. Verify the server before retrying. Purchases One server and one button are free with unlimited runs. Pro is a one-time purchase for additional items. Restore is available in Settings and on the Pro screen. Existing buttons remain usable during store failures. Use the same Apple Account to restore. Reporting a problem Note the app version, iOS version and the broad error shown. Do not send passwords, keys, server addresses, commands or output. Visit Settings → Support website to open a GitHub support request. Requests are public; share only non-sensitive details.
시작하기 1. 서버 주소·SSH 포트·사용자 이름을 추가하세요. 2. 비밀번호를 저장하거나 암호화되지 않은 Ed25519 OpenSSH / ECDSA PEM 키를 가져오세요. 3. 저장하면 연결 테스트가 시작됩니다. 신뢰할 수 있는 경로로 SHA256 지문을 확인하고 승인하면 인증 확인이 계속됩니다. 4. 성공 화면에서 첫 버튼 만들기를 선택하세요. 조회용 예제를 고르거나 검증한 비대화형 명령을 입력하고 저장한 뒤 버튼을 누르세요. 연결 문제 SSH 활성화 여부·포트·사용자 이름을 확인하세요. RSA, 암호화 키, 다단계 인증, 대화형 sudo 입력은 지원하지 않습니다. Mac이 잠들어 SSH 접속이 불가능한 경우 먼저 깨워야 합니다. Wake-on-LAN은 포함되지 않습니다. 안전한 실행 실행 전 확인은 기본 활성화됩니다. 한 번에 하나만 실행합니다. 연결은 전체 15초, 명령은 15~300초로 제한됩니다. 출력은 64KB까지 보관합니다. 취소는 연결을 닫지만 원격 작업의 중단을 보장하지 않습니다. 재실행 전 서버 상태를 확인하세요. 구매 서버 하나와 버튼 하나는 실행 횟수 제한 없이 무료입니다. Pro는 항목을 더 추가하기 위한 일회성 구매입니다. 설정과 Pro 화면에서 복원할 수 있습니다. 스토어 장애가 발생해도 기존 버튼은 계속 사용 가능합니다. 동일한 Apple 계정으로 복원하세요. 문제 신고 앱 버전·iOS 버전·표시된 오류 분류를 확인하세요. 비밀번호·키·서버 주소·명령·출력은 보내지 마세요. 설정 → 지원 웹사이트에서 GitHub 문의를 작성할 수 있습니다. 문의는 공개되므로 비민감 정보만 작성하세요.
