Quick start 1. Add your server’s address, SSH port and username. 2. Save a password or import an unencrypted Ed25519 OpenSSH / ECDSA PEM private key. 3. Choose Test connection from the server menu. Verify the SHA256 host fingerprint through a trusted channel, accept it, then test again. 4. Add a named, non-interactive command and tap its button. Connection issues Check SSH is enabled, the port is reachable and the username is correct. RSA, encrypted keys, keyboard-interactive/MFA and interactive sudo prompts are not supported. A sleeping Mac must already be reachable for SSH; Wake-on-LAN is not included. Safety Confirmations are on by default. Only one command runs at a time. Connecting has a 15-second overall limit; commands have a configurable 15–300-second limit. Output is capped at 64 KB. Cancellation closes the connection, but does not guarantee the server stopped its process. Verify the server before retrying. Purchases One server and one button are free with unlimited runs. Pro is a one-time purchase for additional items. Restore is available in Settings and on the Pro screen. Existing buttons remain usable during store failures. Use the same Apple Account to restore. Reporting a problem Note the app version, iOS version and the broad error shown. Do not send passwords, keys, server addresses, commands or output. Contact support on GitHub. Requests are public. Share only non-sensitive reproduction steps and app/iOS versions.
